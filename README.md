### ✨ Features
- **Matrix Rain UI:** Dynamic terminal-style background.
- **Real-time Conversion:** Instant results as you type.
- **Multi-format Support:** ASCII, Base64, Base32, and Binary.
- **Responsive:** Fully optimized for all screen sizes.
